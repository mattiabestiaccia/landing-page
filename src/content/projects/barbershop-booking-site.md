## Overview

Sito vetrina con sistema di prenotazione online per un barbiere indipendente (singolo operatore). Slot di disponibilità calcolati in tempo reale tramite Google Calendar API.

## Key Features

- **Prenotazione online** con slot calcolati in tempo reale
- **Conferma e cancellazione** via email (Resend)
- **Pannello admin protetto** (JWT) per gestione servizi, orari e blocchi
- **Storage contenuti** admin su Vercel Blob
- **Test-Driven Development** con Vitest
