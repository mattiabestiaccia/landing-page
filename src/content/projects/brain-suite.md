## Overview

Framework di brainstorming strutturato per Claude Code. Trasforma l'ideazione di prodotto in un processo dimension-by-dimension con dialogo socratico interattivo e artefatti persistenti.

## Key Features

- **6 dimensioni strutturate** — product, tech, market, business, competitors, users
- **Dialogo socratico** — agente brain-explorer con domande una alla volta, build on answers
- **Tre modalità** — Socratic (default), Challenger (devil's advocate), Creative (divergent)
- **Artefatti persistenti** — IDEA.md, dimension files, session logs in `.brainstorm/`
- **GSD-ready handoff** — genera documento pronto per `/gsd:new-project`
- **Installazione senza conflitti** — coesiste con GSD e altre estensioni Claude Code via symlink
