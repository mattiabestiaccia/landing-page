## Overview

Machine learning project for land cover classification from aerial imagery using multiple feature extraction techniques: RGB statistics, Wavelet Scattering Transform (WST), and hybrid approaches.

## Key Features

- **Multiple feature methods** — RGB stats, WST, and hybrid approaches
- **Noise robustness evaluation** — Gaussian, Poisson, Salt & Pepper, Speckle, Uniform
- **Automated experiment pipeline** — Batch training and analysis scripts
- **Research paper materials** — Figures and methodology documentation included
